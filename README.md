# DARKCLAW — сайт для GitHub Pages

Готовый статический многостраничный сайт. Никаких npm, серверов, React или сборки: обычные HTML, CSS и JavaScript.

## Страницы
- `index.html` — главная.
- `server.html` — сервер Garry’s Mod.
- `rpc.html` — сообщество RPC.
- `events.html` — концепты ивентов, фильтры и окно с подробностями.
- `404.html` — страница ошибки.

## Что поменять перед публикацией
В файле **`script.js`** вверху в `SITE_CONFIG` укажи:

```js
serverAddress: 'ВАШ_IP:27015',
discordInvite: 'https://discord.gg/ВАШ_КОД',
```

Не вставляй выдуманные значения: пока настройки пустые, сайт объясняет, что адрес или ссылка не настроены.

Коллекция Steam Workshop уже прописана: `3824762059`. Проверь её актуальность. На странице сервера указаны последние известные параметры (`rp_bangclaw`, DarkRP, 8 игроков, порт 27015); если ты изменил конфигурацию сервера, обнови эти данные в `server.html`.

В `EVENT_DATA` в `script.js` можно менять карточки, описания, добавлять ивенты и заменять демонстрационные идеи реальными анонсами. **Текущие карточки — концепты без подтверждённых дат**, не расписание.

## Публикация на GitHub Pages
1. Создай новый публичный репозиторий на GitHub, например `darkclaw`.
2. **Распакуй ZIP и загрузи все файлы в корень репозитория.** Загружать один ZIP как файл не нужно.
3. Открой `Settings → Pages`.
4. В разделе `Build and deployment` выбери `Deploy from a branch`, ветку `main`, каталог `/ (root)` и сохрани.
5. Сайт откроется по адресу вида `https://ТВОЙ_ЛОГИН.github.io/darkclaw/`.

Все пути относительные: сайт работает и в подпапке GitHub Pages `/<repository>/`. Можно также локально открыть `index.html` двойным кликом.

## Файлы
Все файлы должны лежать **рядом в одной папке / корне репозитория**, без вложенных папок:

```text
index.html
server.html
rpc.html
events.html
404.html
style.css
script.js
logo.png
favicon.png
README.md
```

## Возможности
- Адаптивный сайт для компьютеров и телефонов.
- Отдельные URL для всех разделов, мобильное меню и плавные переходы.
- Фильтры и интерактивные карточки ивентов.
- Копирование адреса сервера, Steam-подключение после настройки IP.
- Прямая ссылка на Workshop.
- Пользовательский логотип из предоставленного изображения, без внешних библиотек.
- Никаких вымышленных цифр онлайна и фиктивных дат.

**Важно:** GitHub Pages — статический хостинг. Для живого мониторинга статуса Garry’s Mod, регистрации на ивенты или админки потребуется отдельный сервис/API; в этой версии они не имитируются.
