# DarkClaw — GitHub Pages

Готовый сайт сообщества в чёрно-фиолетовом стиле.

Страницы: `index.html` (главная), `server.html` (Garry’s Mod), `rpc-rp.html` (RPC RP), `rpc-vrchat.html` (миры и аватары VRChat), `events.html` (ивенты).

Все файлы размещаются **в корне репозитория GitHub**, без папок. В GitHub Pages выбери Settings → Pages → Deploy from a branch → main / (root).

Ссылки на Discord, Telegram, YouTube, Twitch и RPC уже добавлены. Сервер Garry’s Mod отмечен как находящийся в разработке, подключение отключено. Ивенты — идеи без назначенных дат.
