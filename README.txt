DARKCLAW v6 — GitHub Pages / no folders

1. Удали старые файлы из репозитория.
2. Распакуй этот архив.
3. Загрузи ВСЕ файлы прямо в корень ветки main.
4. GitHub Pages: Settings -> Pages -> Deploy from a branch -> main / (root).

Новые функции v6:
- Interactive Network Map
- Ctrl+K Command Palette
- Ctrl+~ DARKCLAW Terminal
- Archive Vault
- Achievement System
- Local Live Activity Feed
- Configurable Event Countdown
- Enhanced Shadow Node
- Защита изображений сохранена

Чтобы включить реальный таймер ивента:
в index.html найди id="event-countdown" и заполни data-event-time ISO-датой,
например: data-event-time="2026-09-12T20:00:00+05:00"

Профиль ARI Em НЕ открывается автоматически. Только по ручному клику.
